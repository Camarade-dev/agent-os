# Neon Serpents CLI 001 contract-fidelity audit

The original goal required a polished new Canvas 2D browser game, zero dependencies, eight exact paths, and fifteen numbered criteria spanning arena/camera motion, pointer steering, boost, twelve bots, collisions, death/respawn, collectibles, leaderboard, restart lifecycle, debug API/overlay, approximate FPS, robustness, and documentation. The legacy projection retained only `index.html`, `style.css`, and `LOCAL_DEV.md`; it lost `src/main.js`, `src/game.js`, `src/entities.js`, `src/bots.js`, and `src/render.js`. Its four generic checks replaced all fifteen explicit criteria.

The exact `bug_fix` cause was substring matching: `bug` matched inside `debug`. The bug-fix shortcut then forced low complexity when no legacy high-complexity keyword was present; local-only/small-batch language further biased the score while criterion, path, subsystem, lifecycle, architecture, and verification breadth were not counted. The zero-dependency choice was lost because intake authority was not carried into the reduced plan/ledger packet, reopening an already-resolved dependency gate.

The first instruction exposed a four-item progress ledger and a domain-shaped file list, not the complete eight-path/fifteen-criterion authority. The raw goal was stored in goal intake but was neither embedded nor referenced through an immutable artifact, so the agent could not reliably recover the omitted contract. It rationally produced a monolithic flat Snake implementation against the narrower packet. Four writes and four checks were internally consistent with that projection, so the old completion logic declared success; semantically it was false because the projection itself was incomplete.

The fallback logic was shaped around Pixel Wanderer: root HTML/CSS/JS/docs plus generic canvas, controls, collectible/score, style, and usage checks. That fits its compact architecture but cannot preserve richer or cross-domain missions. The defect is contract preservation, not game generation.

RUN 042 makes raw goal authority immutable, parses structure before lexical heuristics, preserves exact nested paths and numbered criteria, separates verifier availability, diagnoses misplaced substitutes, closes explicit goal choices, checks instruction fidelity, and centralizes completion eligibility. Retrospective repair preserves historical `completed` and three raw decisions while yielding `verification_capability_gap`: four legacy static passes cannot satisfy the fifteen-criterion contract.
