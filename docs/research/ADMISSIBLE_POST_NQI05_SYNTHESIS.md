## Executive result

The accepted NQ-I01→NQ-I05 chain did **not** uncover a hidden
Admissible-specific continuity primitive. It progressively localized the only
surviving hard effect-settlement problem away from decision/orchestration and
onto the physical effect boundary.

At the accepted post-NQI05 synthesis point:

- no research-novel Admissible primitive was established;
- no generic semantic-admission treatment branch survived;
- no decision/orchestration-owned continuity-necessity witness survived the
  accepted workload chain;
- a bounded NQ-I05 effect-boundary residual requirement remained inside the
  frozen causal-topology universe;
- Admissible ownership of that residual was not established;
- M2 remained conditional experimental-validity apparatus;
- industrial/system value remained open and unrefuted.

The fundamental continuity-necessity branch therefore closed rather than
continuing into another question by inertia.

## Canonical architectural consequence

The accepted synthesis states the defensible architecture as:

```text
model / planner
→ proposes action
→ Admissible
→ checks authority/evidence/policy and the effect contract it has been given
→ authorizes, refuses, or asks for evidence/authority
→ effect boundary
→ owns the physical commit semantics it is actually capable of owning
→ returns grounded effect evidence/status when available
```

The invalid inference is that Admissible creates authoritative physical-effect
truth merely by keeping more history or relocating settlement state into its own
orchestration layer.

The value of continuity work after NQI is therefore architectural honesty:
Admissible must know which effect guarantees it can rely on and refuse when a
required guarantee is unavailable. The guarantee itself is not made
Admissible-specific by this result.

## M2 disposition

M2 is **not** a surviving research thesis here.

Its retained role is conditional experimental-validity apparatus when a selected
experiment actually requires physically justified scored→executed/effect
identity. It is not a presumed minimum substrate, a novel security primitive, or
an automatically necessary part of future work.
