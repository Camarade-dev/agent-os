Admissible — Local Provider Settings

Local only. Secrets configured here stay on your machine. Do not commit .admissible/local_provider_settings.json or raw tokens to Git. Prefer setting api_key_env_var and exporting the token in your shell.

Environment variables

VariableRequiredDefault
ADMISSIBLE_HF_TOKENYes—
ADMISSIBLE_HF_MODELYes—
ADMISSIBLE_HF_BASE_URLNohttps://router.huggingface.co/v1
ADMISSIBLE_HF_TIMEOUT_SECONDSNo60

Generate settings JSON (CLI)

python -m admissible.harness.provider_settings --out .admissible/local_provider_settings.json

PowerShell example

# Set token locally (do not commit)
$env:ADMISSIBLE_HF_TOKEN="<your-token>"
$env:ADMISSIBLE_HF_MODEL="<model>"
$env:ADMISSIBLE_HF_BASE_URL="https://router.huggingface.co/v1"

Run demo trace (opt-in live)

python -m admissible.runner.demo_trace `
  --demo-pack benchmark/reports/demo-pack.json `
  --gold benchmark/annotations/gold_labels.jsonl `
  --provider hf `
  --trace-out benchmark/reports/hf_demo_trace.json `
  --html-out benchmark/reports/hf_demo_trace.html
